למה זה בטוח לתת Publish? שרת ה-MCP לעולם לא מבקש את ה-OAuth scope של tagmanager.publish, כך ש-Google חוסמת פרסום ל-Live ברמת ה-token — גם אם למשתמש יש הרשאת Publish. בנוסף, כלי הפריסה בודק את סוג ה-environment ומסרב ל-Live ול-Latest.

🛠️ שלבי ההגדרה ב-GTM (כ-2 דקות)

  1. היכנס ל-Google Tag Manager.
  2. לחץ על Admin (ניהול).
  3. בעמודת החשבון לחץ על User Management (ניהול משתמשים).
  4. מצא את mcp-ga-gtm-readonly@chen-web-500809.iam.gserviceaccount.com ולחץ עליו.
  5. תחת Container Permissions של drchenpardo.co.il בחר Publish.
  6. שמור.
  7. ב-VS Code: פתח את .vscode/mcp.json ולחץ Restart מעל השרת chenIntegrations.

🧰 הכלים החדשים בשרת ה-MCP

  • gtm_list_triggers / gtm_list_variables / gtm_get_tag — קריאה
  • gtm_create_tag / gtm_update_tag — יצירה ועדכון תגים
  • gtm_create_trigger / gtm_create_variable — טריגרים ומשתנים
  • gtm_create_version — יצירת גרסה מה-workspace (ללא פרסום)
  • gtm_deploy_version_to_environment — פריסה ל-environments מותאמים בלבד (Development)
תהליך עבודה מומלץ: עריכה ב-workspace ← gtm_create_version ← פריסה ל-Development עם gtm_deploy_version_to_environment ← בדיקה באתר עם snippet של ה-Development environment ← פרסום ל-Live ידנית מממשק GTM כשמרוצים.
